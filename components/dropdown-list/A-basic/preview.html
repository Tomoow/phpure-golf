Dropdown list — A-basic

PHPure Golf brand variant of the Hyvä UI 2.7.1 dropdown-list. Figma nodes 1343:42718 (container) and 1343:42177 (item, 24 leaf variants). The container is a <ul role="listbox"> driven by the @utility dropdown-list shell; rows use @utility dropdown-list__item with state selectors on aria-selected, aria-disabled, and data-active. Alpine supplies keyboard navigation, selection, and roving-focus; CSS paints the states.

Example 2 — Alpine-wired combobox

A trigger toggles the list. Click outside to close. Keyboard nav: Arrow keys, Home / End, Enter / Space to select, Escape to close. The trigger label updates from the dropdown:select event.
