Product Card — A-basic

PHPure Golf brand variant of the Hyvä UI 2.7.1 product-card molecule. Figma node 2256:7466. Composes five approved atoms (btn, swatch, review-summary, status, form-checkbox) plus nine card-local sub-elements (product-card shell, __image-frame, __image, __badge, __price-row, __description, __brand, __title, __action-row, __body). Eight variant leaves: Desktop / Mobile × Grid / List × default / promo. The matrix below renders one card per leaf plus an out-of-stock state demo.

Desktop Grid — 2 cards (default, promo)

Cards at their natural 376 px width inside a 1280 px viewport breakpoint. Default = no promo badge, single price in slate-blue-800. Promo = red `-20%` ribbon hanging from top, current price flips to red-600, strikethrough old price at 18 px (Desktop Grid uses the larger old-price size — PC-3).
