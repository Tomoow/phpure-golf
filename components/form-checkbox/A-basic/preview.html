Form checkbox — A-basic

PHPure Golf brand variant of the Hyvä UI 2.7.1 form-checkbox shell. Figma node 1420:30806. The shell is one @utility form-checkbox on the wrapping <label> driven by CSS custom properties and :has() state selectors — no per-state utilities, no Alpine. The indeterminate visual is a CSS-drawn ::after bar (no SVG); the checkmark is the canonical Heroicons outline-24 check rendered inline as an <svg> inside .form-checkbox__box.

State matrix — Size M (default)

Three variants (Unchecked / Checked / Indeterminate) × four states (Default / Hover / Focus-visible / Disabled). Forced-state classes simulate the visual without real interaction. The "Live" interactive section below lets you exercise the actual :hover / :focus-visible / :checked selectors with the keyboard or mouse.

Size ladder (S / M / L)

Three sizes — form-checkbox--sm (16 px box / 12 px glyph), form-checkbox (20 px box / 16 px glyph, default), and form-checkbox--lg (24 px box / 16 px glyph). Sizes S and M add padding-block: --spacing(1) to the wrapping label so the touch target reaches ≥24×24 px (WCAG 2.5.8). Size L already meets the threshold without padding.

Stacked layout (label + hint text)

The .form-checkbox__text column flexes to a column when a hint is present, and the hint sits underneath the label aligned to the label start. The <input> gets aria-describedby pointing at the hint id so screen readers read both.

Feedback modifiers (error / warning / success)

Each modifier overrides only the border + focus tokens — the box bg / glyph stay brand-correct so the user's selection remains legible. The hint text picks up its color from form-group__hint--* (the same utilities used by form-field). Error is the most common ("you must accept the terms"); warning + success ship for parity.

Interactive (click / Tab + Space to toggle)

Real <input type="checkbox"> elements — no Alpine, no JavaScript. Click anywhere on the label to toggle, or Tab to focus and press Space. Indeterminate is seeded by an external module script (see seed-indeterminate.js), which sets el.indeterminate = true on the checkbox with the matching id. The script has no event handlers — CSP-safe.

Group of checkboxes (<fieldset> + <legend>)

When several checkboxes share a question, wrap them in a <fieldset class="form-checkbox-group"> with a <legend class="form-checkbox-group__legend">. <fieldset> + <legend> is the simplest WCAG 1.3.1 / 4.1.2 compliant grouping. The shipped utility strips the native fieldset border / margin so the rows read as a flat stack.
