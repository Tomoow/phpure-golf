Form field — A-basic

PHPure Golf brand variant of the Hyvä UI 2.7.1 form-field shell. Figma nodes 1329:15249 (base) and 1331:14308 (variants). The shell is one @utility form-field + feedback modifiers; every "variant" is HTML composition inside the shell (see spec §6). This preview renders every composition pattern in every relevant state so the design lead can verify parity against Figma.
