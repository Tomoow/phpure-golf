Reviews summary — A-basic

PHPure Golf brand variant of the Hyvä UI 2.7.1 review-summary atom. Figma node 1385:28923. ONE @utility review-summary on the row drives every visual through CSS custom-property slot tokens (--review-fill, --review-gap-slots, --review-gap-inline). Three slots (Leading, Stars, Trailing) compose by inclusion / omission of children — no root-level variant modifiers needed. Read-only display only — no hover / focus / active. Filled stars at champagne-beige-700, empty track at slate-blue-200. Fractional fill driven per-row by inline style="--review-fill: 0..1" — the ONE whitelisted inline style for this atom.

Variant grid — 12 representative leaves

The full Figma set has 24 leaves (3 Leading values × 2 Stars values × 4 Trailing values). Here are 12 representative combinations covering both star-present and star-absent rows. The --review-fill demo value is 0.82 (= "4.1 / 5") for every row that includes stars, matching the trailing "4.1" score. The empty-state leaf (no stars, no leading, no trailing) renders nothing — section 4 covers that.

Empty state — no reviews yet

Per RV-6, the atom renders nothing when no data is supplied (the literal Figma string "[Empty Reviews summary component]" is a Figma-authoring guard rail, not a runtime element). Consumers that prefer a degraded "no reviews yet" affordance can compose the optional .review-summary__empty-fallback span — DM Sans 14/20 weight 500, slate-blue-500 — as the sole child of .review-summary.
