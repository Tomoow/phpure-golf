Swatches — A-swatches-rounded

PHPure Golf brand variant of the Hyvä UI 2.7.1 swatches kit. Figma node 1385:32405. ONE @utility swatch on the wrapping <label> drives every visual through CSS custom properties and :has() state selectors. Three types (swatch--color, swatch--text, swatch--image), two shapes (default round + swatch--rectangle), five sizes (XS / S / M / L / XL). No Alpine — state lives in the native <input type="radio"> or <input type="checkbox">. Color swatches receive their product hex via style="--swatch-bg: #14B8A6" — the ONE inline-style whitelist for this utility. Every other token resolves to theme.css.

State matrix — Size M, Round shape (default)

Three types (Color / Text / Image) x five states (Default / Hover / Focus-visible / Selected / Disabled or Out-of-stock). Forced-state classes simulate the visual without real interaction. Size ladder — XS / S / M / L / XL

Five sizes per spec §5. XS and S add wrapping-label padding so the touch target meets WCAG 2.5.8 (>=24x24). The chip itself stays at the size value. 2XL / 3XL are deferred to v2 — that tier is better expressed as a card pattern (OQ-SW-5).

Shape — Rectangle

swatch--rectangle opts out of the round default. For swatch--color and swatch--image this also swaps the outer-ring palette to blue (per OQ-SW-3, kept for backwards compatibility — round + emerald is the brand-recommended default). Text rectangle keeps emerald rings; only the radius changes to md.

Real <input type="radio"> elements grouped by <fieldset>. Click any swatch or Tab into a fieldset and use arrow keys to cycle. Disabled fieldset

Native <fieldset disabled> cascades the disabled state to every descendant input. The shell's :has(:disabled) selector fires per-swatch so each chip carries the diagonal slash + reduced opacity.

Material (locked)

Invalid fieldset (group-level error)

Per OQ-SW-10, the swatch shell does NOT add per-option invalid borders — a per-option red ring would conflict with the selected ring. The error is communicated at the field-group level via form-group__hint--error, which the consumer applies to the legend's adjacent message.

Multi-select facet (filter context)

Layered-nav style: <input type="checkbox"> instead of radio. The shell's :has(:checked) selector matches both — the consumer chooses the input type. swatch-group--tight reduces the gap to 4 px for dense facet rows.
