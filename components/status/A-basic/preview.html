Status — A-basic

PHPure Golf brand variant of the Hyvä UI 2.7.1 stock-status atom. Figma node 1385:32111. ONE @utility status on the wrapping <span> drives every visual through CSS custom-property slot tokens (--status-color, --status-gap, --status-label-color). Two styles (status--dot, status--icon) × five statuses (status--in-stock, status--out-of-stock, status--stock-status) = 10 leaves. Non-interactive — no hover / focus / active / disabled states. The textual label is the canonical indicator at slate-blue-800; the glyph is decorative reinforcement that picks up the per-status color via currentColor.

Variant matrix — 2 styles × 5 statuses

All ten leaves on white. Row 1 uses the Coloured-Dot style (status--dot, 12×12 filled-circle SVG, 6 px gap); row 2 uses the Icon style (status--icon, 20×20 Heroicons solid SVG, 4 px gap). Status semantics: in-stock / in-stock-count / count-in-stock all share emerald-500 + check-circle; out-of-stock uses rose-500 + x-circle; stock-status (warning / fallback) uses amber-500 + exclamation-circle. The label always stays slate-blue-800 — the per-status color modifier does NOT tint the text.

Long label / nowrap behavior

Per Figma + ST-5, the atom sets white-space: nowrap on the label. The indicator's intrinsic width grows with the label content — it does NOT wrap to two lines, and it does NOT clip. Overflow handling is the consumer parent's responsibility (truncation with ellipsis, marquee, sr-only fallback, etc.). Below: a long urgency-message label at full width, the same label inside a 12-rem constrained card (overflows the card's right edge), and the same label inside a card with overflow: hidden + ellipsis applied BY THE CONSUMER (not by the atom).

Consumer-applied truncation (overflow: hidden + ellipsis on a wrapper)

When truncation is required, the consumer wraps the atom in an overflow: hidden / text-overflow: ellipsis container. The atom itself remains white-space: nowrap; the wrapper clips.
