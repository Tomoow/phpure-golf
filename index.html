Components (Phase 1)

  • buttons — A-basic approved 2026-04-24

    Primary / Secondary / Tertiary / Transparent × 5 sizes × default / hover / active / disabled / focus, plus icon-leading, icon-trailing, icon-only and icon-only round.

  • form-field — A-basic approved 2026-04-24

    Shell + bare input skeleton (Tailwind v4 @utility) with feedback modifiers (error / warning / success). Composes into text, email, password, search, currency, phone, datepicker, stepper, textarea. Country selector is a live Alpine combobox built on the dropdown-list molecule (trailing chevron opens the panel).

  • dropdown-list — A-basic approved 2026-04-24

    Floating menu panel with first Alpine-powered combobox: ↑/↓/Home/End/Enter/Esc keyboard nav, selected & disabled states, leading icon / image / flag slots, trailing check or hint text, empty / loading placeholders. Replaces native <select> where a styled dropdown is required.

  • form-checkbox — A-basic approved 2026-05-08

    Native <input type="checkbox"> styled via appearance: none with a custom check / indeterminate glyph. One @utility form-checkbox shell driven by :has() state selectors — mirrors the form-field architecture. 3 variants × 4 states × 3 sizes, plus error / warning / success feedback modifiers and a <fieldset>+<legend> group wrapper. CSS-only, indeterminate seeded via a one-line module script.

  • swatches — A-swatches-rounded approved 2026-05-08

    Color / size-text / image swatches typically used inside product cards and on PDPs. One @utility swatch shell on a wrapping <label> with type / shape / size modifiers and :has() state selectors — same architecture as form-checkbox. Selected = Additional/Swatch inner shadow + 2 px outer ring. Out-of-stock = diagonal slash via CSS gradient. CSS-only, native <input type="radio"> for single-select, checkbox for facets. Real product hex colors set via inline --swatch-bg (the only documented inline-style exception).
